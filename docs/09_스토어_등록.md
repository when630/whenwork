# Microsoft Store 등록

> WHENWORK Windows판을 Microsoft Store에 올린다(설계 D-P16). 패키지(MSIX) 준비는 끝나 있고, 남은 것은 개발자 계정·이름 예약·제출이다. 2026-11-15 작성.

## 순서

| # | 할 일 | 누가 |
|---|---|---|
| 1 | [storedeveloper.microsoft.com](https://storedeveloper.microsoft.com)에서 **개인(Individual)** 개발자로 가입. 무료, 신분증과 셀피로 본인 확인 | 사용자 |
| 2 | Partner Center → 앱 및 게임 → 새 제품 → **MSIX 또는 PWA 앱** → 이름 `WHENWORK` 예약 | 사용자 |
| 3 | 제품 관리 → **제품 ID**에서 세 값을 옮겨 적는다: `Package/Identity/Name`, `Package/Identity/Publisher`(`CN=…`), `Package/Properties/PublisherDisplayName` | 사용자 → 개발 |
| 4 | `package.json`의 `build.appx.identityName`·`publisher`·`publisherDisplayName`을 그 값으로 바꾸고 `npm run build:store` | 개발 |
| 5 | 아래 "제출 내용"대로 채우고, 4의 `.appx`를 패키지로 올려 제출 | 사용자(개발이 옆에서) |
| 6 | 심사 통과 뒤 사이트의 Windows 받기 버튼을 Store 링크로, "설치 파일 직접 받기"는 그 아래로 | 개발 |

가입할 때 **게시자 표시 이름**은 `WHENDESK`로 한다(시리즈 이름, 사이트·약관의 상호와 같다).

## 패키지 상태 (0.4.0으로 빌드 확인)

- `npm run build:store` → `dist/WHENWORK-<버전>-win-x64.appx`. 서명은 Store가 한다.
- 매니페스트(`assets/appx/AppxManifest.xml`): `runFullTrust`, `unvirtualizedResources`, `FileSystemWriteVirtualization=disabled`(데이터를 `%APPDATA%\whenwork`에 두어 앱을 지워도 남게), `whenwork://` 프로토콜, 로그인 시 시작(`StartupTask`).
- Store판은 자체 업데이트를 하지 않는다(`process.windowsStore` → "스토어가 업데이트합니다").
- 지금 `identityName`·`publisher`는 자리표시자(`when630.WHENWORK`, `CN=WHENWORK-Dev`) — 3·4단계에서 바꾼다. 바꾸지 않으면 업로드가 거절된다.

## 제출 내용

### 가격 및 사용 가능 여부
- 시장: 모든 시장(언어는 한국어 하나 — 원하면 대한민국만)
- 가격: **무료**
- 앱 안 결제: Store 결제를 쓰지 않고 자체 결제(Paddle)로 Lite·Pro를 판다. 게임이 아닌 앱은 허용된다(Store 정책 10.8.7). 목록 설명에 "무료, 일부 기능은 유료(Lite·Pro)"를 적는다.

### 속성
- 범주: **생산성**
- 개인정보처리방침 URL: `https://whendesk.app/legal/privacy`
- 웹사이트: `https://whendesk.app/work`
- 지원 연락처: `support@whendesk.app`
- 시스템 요구 사항: Windows 10 1809(17763) 이상, x64

### 연령 등급(IARC 설문)
- 폭력·성적 내용·약물·도박·욕설: 없음
- 사용자끼리 대화·공유: 없음
- 위치 공유: 없음
- 개인 정보 수집: 있음 — 구매 복원용 이메일, (Pro를 켠 경우) 암호화된 백업·동기화 데이터
- 디지털 상품 구매: 있음(Lite·Pro, 앱 밖 결제)
- 예상 등급: 전체 이용가

### 제한된 기능 사유 (영문으로 적는다)
- `runFullTrust`: *WHENWORK is a desktop (Electron/Win32) app. It needs full trust for its system-tray icon, global keyboard shortcuts for quick capture, and Windows notifications.*
- `unvirtualizedResources`: *User data (tasks and projects) is stored in %APPDATA%\whenwork, the same folder the standalone installer uses. Turning off file-system write virtualization keeps a user's tasks when the app is uninstalled or reinstalled, and lets users who move from the standalone installer to the Store version keep their existing data. Without it, uninstalling the Store app would silently delete all of the user's tasks.*

**설명**
> 생각난 할 일, 단축키 한 번에.
>
> WHENWORK는 트레이에 머물다가 부르면 뜨는 할 일 앱입니다. 어디서든 Ctrl+Alt+Space를 누르고, 적고, Enter. 할 일이 인박스에 들어갑니다. 계정도, 따로 설치할 것도 없습니다.
>
> • 퀵캡처 — 어떤 프로그램을 쓰다가도 단축키 한 번으로 한 줄 적어 던져 둡니다. 적는 순간 디스크에 먼저 저장되어 잃지 않습니다.
> • 오늘 뷰 — 오늘 볼 것만 프로젝트별로 묶어 보여 줍니다. ↓로 내려가고 Space로 끝냅니다. 마감이 가까운 일은 따로 표시됩니다.
> • 프로젝트 — 인박스에서 고르고 숫자 키 하나(1~9)로 프로젝트를 정합니다.
> • 대기 — 남에게 맡기고 기다리는 일을 따로 모으고, 얼마나 기다렸는지 보여 줍니다.
> • 검색 — 초성으로도 찾고, #프로젝트·마감·정렬을 섞어 씁니다.
> • 아침 브리핑 — 정한 시각에 오늘 할 일과 마감이 지난 일을 알려 줍니다.
> • 내 데이터 — 이 PC에 저장되고, JSON 파일 하나로 내보내고 되살립니다.
>
> 무료로 모든 기본 기능을 씁니다(프로젝트 3개까지, 오늘 뷰 아래 광고 한 줄).
> Lite(9,900원, 한 번 결제) — 광고 없음, 프로젝트 제한 없음.
> Pro(연 19,800원) — Lite의 모든 기능 + 자동 클라우드 백업 + 기기 간 동기화. 백업과 동기화는 이 PC에서 암호화한 뒤 올라가 서버는 내용을 읽을 수 없습니다.
>
> 결제는 Paddle이 처리합니다. 구매 후 14일 안에는 이유를 묻지 않고 환불합니다.

## 주의

- 첫 제출 심사는 보통 며칠 걸린다. `unvirtualizedResources`가 거절되면 설계 D-P16의 대안(가상화를 받아들이고 첫 실행 안내 + 제거 전 내보내기 안내)으로 바꾼다.
- 버전은 `0.4.0` → 패키지 `0.4.0.0`. Store에 올린 뒤에는 같은 버전을 다시 올릴 수 없으니, 고쳐서 다시 낼 때는 버전을 올린다.
- Store판과 설치 파일판은 데이터 폴더가 같다 — 둘 다 깔면 같은 할 일을 본다(동시에 켜지는 것은 단일 인스턴스 락이 막는다).
