WHENWORK UI 목업 v0.1

설계 v1.0 기준 검토용 정적 목업. 다크 단일 테마 · 키보드 중심 · 정보 밀도 높음 (페르소나 역산).

01

퀵캡처 팝업

빈 상태 · 입력 중 · 저장 완료 · DB 오프라인(큐 대기) 4개 상태

 02

오늘 뷰 (트레이 창)

오늘 · 인박스(AI 분류 제안) · 대기 탭 + 빈 상태/오프라인 푸터

 03

재개 카드

정상 · 생성 중(스켈레톤) · AI 실패 3개 상태

 04

결정 후보군 (기록용)

프로젝트 인지 · 단축키 · 악센트 색 — 선택 완료, 근거 기록으로 보존

이 목업이 주장하는 것 (동의하면 확정)

  • 다크 단일 테마 — 라이트 모드 없음. IDE 다크 환경 옆에 뜨는 창이라는 전제
  • 탭 3개 고정 (오늘/인박스/대기) + 숫자키 전환. 프로젝트 목록 화면은 따로 없음 — 재개 카드는 항목에서 Enter로 진입
  • AI 생성물은 전부 ✦ 보라 표식 — 사람 입력과 항상 시각 구분
  • DB 오프라인은 에러가 아니라 상태 — 푸터 LED·황색 한 줄로만 표현 (D1)
  • 다음 액션은 항상 1개 — 재개 카드에 목록 금지
